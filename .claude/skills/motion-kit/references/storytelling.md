# Estructuras narrativas listas para usar

Cada «bloque» = una idea = un plano. 1 bloque ≈ 1,5–3 s en formato corto.

## Reel / TikTok (contenido)
1. **Hook (0–2 s)**: promesa, cifra impactante, pregunta, contradicción. ≤ 7 palabras.
2. **Contexto (2–5 s)**: por qué importa.
3. **Valor (5–25 s)**: lista numerada, pasos, antes/después. Un punto por bloque.
4. **Payoff**: la revelación / el resultado.
5. **CTA suave**: «Guárdalo», «Sígueme para la parte 2», «Comenta X».
→ Composición: `Kinetic-Reel` (un bloque = una entrada de `beats`).

## Promo de producto / servicio — AIDA
1. **Atención**: hook visual + problema («Deja de perder tiempo»).
2. **Interés**: 2–4 beneficios (no características), uno por escena.
3. **Deseo**: prueba (cifras, logos de clientes, opiniones, captura del producto).
4. **Acción**: CTA explícito + URL / oferta limitada.
→ Composición: `Promo-*` (hook → escenas → CTA).

## Anuncio corto — PAS (Problema, Agitación, Solución)
1. Problema que siente el público. 2. Lo que le cuesta (agitar). 3. El producto como solución + CTA.

## Lanzamiento de producto
Teaser (misterio) → revelado del logo/producto → 3 características en movimiento → cifras
(`MotionStats`) → fecha / CTA.
→ `Logo-*` + `Showcase-*`, o la skill HyperFrames `product-launch-video`.

## Anuncio de evento
Fecha + lugar en el hook → ponentes / programa → beneficio de ir → CTA de inscripción.

## Testimonio / UGC
Resultado del cliente en el hook → situación anterior → clic → resultado con cifras → CTA.

## Reglas de redacción en pantalla
- Frases cortas, verbos de acción, tuteo en redes sociales.
- 1 palabra resaltada por frase (`highlight`) = la palabra que lleva la emoción.
- Nunca más de 2 líneas de texto secundario en pantalla.
- Con voz en off: el texto en pantalla resume, no repite palabra por palabra.
